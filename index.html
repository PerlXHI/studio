Lisensi & penggunaan

Pastikan ketentuan lisensi setiap produk cocok dengan kebutuhanmu sebelum membeli.

Apakah musik boleh dipakai untuk konten monetisasi?

Ketentuan lisensi dapat berbeda per produk. Konfirmasi cakupan penggunaan komersial kepada Perivelle sebelum membeli.

Bolehkah file dijual ulang atau dibagikan?

Jangan menjual ulang, membagikan file mentah, atau mengklaim musik sebagai karya sendiri kecuali lisensi tertulis menyatakan sebaliknya.

Format file apa yang tersedia?

Format dan detail file perlu dikonfirmasi untuk tiap produk sebelum pesanan diproses.

Tambahkan produk ke keranjang, salin ringkasan pilihan, lalu kirim ke kontak resmi Perivelle untuk konfirmasi harga, lisensi, dan pembayaran. Checkout online belum terhubung.

Apakah form pesanan custom langsung mengirim data?

Tidak. Form hanya membuat ringkasan di perangkatmu; salin hasilnya lalu kirim secara manual. Data tidak disimpan di server.
